# Inferno-daily

Daily Inferno Wave is a single-file, dependency-free practice game. The daily
layout is generated from the UTC date and progress is saved in the browser.

## Host it on GitHub Pages from your phone

1. Open this repository in your phone's browser and sign in to GitHub.
2. Open **Settings** for the repository, then choose **Pages**. If Settings is
   not visible, open the repository's **Code** tab and use its menu to find it.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose the `main` branch and the `/(root)` folder, then tap **Save**.
5. Return to **Settings → Pages** after a minute or two and open the published
   site link shown there. The site loads from `index.html` in the repository root.

If you edit the game on your phone later, open **Code → Add file → Create new
file**, name it `index.html` (or edit the existing file), save the change to
`main`, and Pages will publish the update automatically.
